# Befehle

Alle wichtigen Befehle auf einen Blick, nach Thema geordnet. Für Details folge den
Links zur jeweiligen Seite.

!!! tip "Schreibweise"
    Platzhalter in spitzen Klammern ersetzt du durch echte Werte, z. B.
    `/home <Name>` → `/home basis`.

## Teleport & Homes

Mehr dazu: [Home & Teleport](../zuhause/home-und-teleport.md).

| Befehl | Beschreibung |
|--------|--------------|
| `/sethome <Name>` | Aktuellen Ort als Home speichern |
| `/home` | Menü mit deinen Homes öffnen |
| `/home <Name>` | Zu einem bestimmten Home teleportieren |
| `/delhome <Name>` | Ein Home löschen |
| `/homelist` | Alle deine Homes auflisten |
| `/tpa <Spieler>` | Anfragen, zu einem Spieler teleportiert zu werden |
| `/tpahere <Spieler>` | Einen Spieler bitten, zu dir zu kommen |
| `/tpaccept` | Teleport-Anfrage annehmen |
| `/tpdeny` | Teleport-Anfrage ablehnen |
| `/spawn` | Zum Server-Spawn |
| `/warp <Name>` | Zu einem öffentlichen Warp-Punkt (z. B. Shop) |
| `/back` | Zurück zur letzten Position (z. B. nach dem Tod) |

## Bauen & Schutz

Mehr dazu: [Claims](../zuhause/claims.md) (Abenteuerwelt) · [Plots](../zuhause/plots.md) (Bauwelt).

### Claims – Abenteuerwelt

| Befehl | Beschreibung |
|--------|--------------|
| `/claim` | Den Chunk beanspruchen, in dem du stehst |
| `/unclaim` | Den aktuellen Chunk wieder freigeben |
| `/claims` | Claim-Übersicht (Menü) öffnen |

### Plots – Bauwelt

| Befehl | Beschreibung |
|--------|--------------|
| `/plot claim` | Den Plot beanspruchen, auf dem du stehst |
| `/plot auto` | Automatisch den nächsten freien Plot zuweisen |
| `/plot home` | Zu deinem Plot teleportieren |
| `/plot trust <Spieler>` | Dauerhaftes Baurecht geben (auch offline) |
| `/plot add <Spieler>` | Baurecht geben, solange du online bist |
| `/plot remove <Spieler>` | Einen Mitspieler entfernen |
| `/plot deny <Spieler>` | Einem Spieler den Zutritt verwehren |
| `/plot visit <Spieler>` | Den Plot eines anderen besuchen |
| `/plot info` | Besitzer und Rechte des Plots anzeigen |
| `/plot biome <Biom>` | Das Biom deines Plots ändern |
| `/plot merge` | Angrenzende eigene Plots zusammenlegen |
| `/plot clear` | Plot zurücksetzen (Inhalt wird gelöscht) |
| `/plot delete` | Plot wieder freigeben |

!!! warning "Vorsicht mit clear & delete"
    `/plot clear` und `/plot delete` löschen alles auf dem Plot **unwiderruflich**.
